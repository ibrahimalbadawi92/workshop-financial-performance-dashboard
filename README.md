# Workshop Financial Performance Dashboard

**This project uses fully synthetic data created for portfolio demonstration purposes. No real company financial data is included.**

## Data Privacy Statement

Every figure in this dashboard — revenue, expenses, profit/loss, employee costs, account-level detail — is generated by [`scripts/generate_synthetic_data.py`](scripts/generate_synthetic_data.py), an independently-authored synthetic dataset built for this Portfolio case study. It is **not** derived from, scaled from, or fitted to any real company's records: no real values were copied, perturbed, or used as a numeric basis in any way. The chart of accounts, account codes, and category names are invented for this project. The one data-quality issue and one data-completeness caveat demonstrated on the Data Quality page are fictional bookkeeping scenarios authored specifically to exercise the dashboard's validation logic.

This is a **case study**, not a disguised real company — there is no real business behind this dashboard.

## Project Overview

A bilingual (Arabic/English) executive financial dashboard for a small workshop business, covering profitability analysis, expense structure, cost drivers, break-even and what-if scenario modeling, and automated data-quality validation. Built with Streamlit, Pandas, and Plotly.

## Business Problem

A small business owner or finance lead needs to answer, at a glance and without a spreadsheet: *Are we making or losing money, where does the money go, what changed year over year, how far are we from break-even, and what would it take to get there?* This dashboard answers all five, in either language, with every figure traceable back to its source account.

## Dashboard Features / Pages

| Page | What it shows |
|---|---|
| Executive Overview | Headline KPIs, revenue vs. expenses trend, profit/loss trend, expense composition, employee-cost snapshot |
| Revenue Analysis | Revenue trend and composition by account, year-over-year revenue comparison |
| Expense Analysis | Expense by management group and by original account, top-N ranking, a heatmap, employee-cost component breakdown |
| P&L Drivers | Revenue/expense movement between two chosen years, an expense change bridge (waterfall), ranked top increases/decreases |
| Year Comparison | Side-by-side KPI comparison and a full account-level detail table between a base year and a comparison year |
| Break-Even Analysis | Current revenue/expenses/result, break-even revenue, and — depending on whether the selected year is profitable or not — either the required revenue increase / expense reduction, or the surplus already achieved above break-even |
| What-If Scenario | User-driven revenue-increase / expense-reduction sliders, showing the resulting scenario P&L against the actual figures |
| Data Quality | Source file path, reconciliation check per year, management-mapping coverage, structural warnings, and the dataset's two fictional data-quality demonstrations |

## KPIs

Total Revenue · Total Expenses · Official Net Profit/Loss · Net Result Margin · Expense-to-Revenue Ratio · Break-even Gap · Employee Costs · Employee Costs / Revenue · Employee Costs / Total Expenses — every formula is shown on request via the in-app info-popover system (a small "i" icon beside each KPI, chart, and table, with Definition / Calculation / How to Read / Notes sections, in both languages).

## Analytical Methods

- **Missing vs. zero distinction**: an account absent from a given year's data is flagged "Not Present," never silently treated as a recorded zero.
- **Aggregated-ratio discipline**: a multi-year ratio (e.g. Expense-to-Revenue for 2021–2023) is always aggregated-numerator ÷ aggregated-denominator, never an average of annual percentages.
- **Profit/loss-symmetric presentation**: every page reads correctly whether a year (or period) is profitable, near break-even, or a loss — including Break-Even Analysis, which shows a surplus-above-break-even view instead of a misleading "required increase" when a year is already profitable.
- **Independent reconciliation**: every year's revenue, expenses, and profit/loss are independently recomputed from account-level detail and checked against the officially reported totals on the Data Quality page.

## Local Setup

```bash
pip install -r requirements.txt
streamlit run app.py
```

The dataset ships pre-generated in `data/`. To regenerate it (e.g. after editing the synthetic-data script):

```bash
python scripts/generate_synthetic_data.py
```
